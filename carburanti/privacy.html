Informativa sulla Privacy per “Prezzi Carburanti”

La presente Informativa sulla Privacy descrive le modalità con cui Roberto Ricci (“Titolare”, “noi”, “nostro”) raccoglie, utilizza e protegge i dati personali degli utenti (“Utente”, “tu”) che utilizzano l’applicazione mobile / sito web “Prezzi Carburanti” (“App”).

Titolare del trattamento dei dati personali

Roberto Ricci ricci.roberto@itssmartacademy.it

Dati Raccolti

Per il corretto funzionamento dell’App e per fornirti i nostri servizi, raccogliamo le seguenti tipologie di dati:

  • Dati forniti volontariamente: Parametri di ricerca inseriti nell’app.
  • Dati richiesti dai permessi del dispositivo: Posizione approssimativa (solo se viene concessa l’autorizzazionea all’app).

Modalità del Trattamento e Utilizzo di API Remote

L’App invia i parametri di ricerca e le coordinate del centro dell’area di ricerca a una nostra API remota. I dati sono conservati su server cloud situati nei Paesi Bassi e forniti da:

  • Railway Corporation, 548 Market St PMB 68956, San Francisco, California 94104, USA

L’App può ottenere le coordinate di cui sopra in due modi:

  • Attraverso i sensori del dispositivo (se l’utente concede l’autorizzazione all’app tramite il sistema operativo o il browser).
  • Inviando la descrizione testuale dell’indirizzo inserita nell’app dall’utente a una API remota fornita da OpenStreetMap (nominatim.openstreetmap.org).

Finalità del Trattamento e Base Giuridica

Trattiamo i tuoi dati esclusivamente per le seguenti finalità:

  • Fornire il servizio richiesto. Base giuridica GDPR: Esecuzione di un contratto (Art. 6, par. 1, lett. b).
  • Risolvere bug e monitorare la sicurezza della nostra API. Base giuridica GDPR: Legittimo interesse del Titolare (Art. 6, par. 1, lett. f).

Comunicazione e Condivisione dei Dati

I dati sono condivisi con:

  • Fornitori di servizi tecnici e di hosting (che agiscono come Responsabili del Trattamento):
    • Railway Corporation
      • Privacy policy: https://railway.com/legal/privacy
      • DPA: https://railway.com/legal/dpa
  • Fornitori di API esterne:
    • OpenStreetMap Foundation
      • Privacy Policy: https://osmfoundation.org/wiki/Privacy_Policy

Conservazione dei Dati

Conserveremo i tuoi dati personali solo per il tempo strettamente necessario a conseguire le finalità per cui sono stati raccolti. Nello specifico:

  • Il software backend conserva i parametri di ricerca e le informazioni sulla posizione per il tempo necessario ad elaborare e trasmettere i risultati.
  • Questi stessi dati potrebbero comparire anche nei log generati dal software backend, che vengono conservati per un massimo di 90 giorni.

Sicurezza dei Dati

Le comunicazioni tra l’App e le API remote sono crittografate con protocollo TLS.
